# Lập Trình Thiết Bị Di Động

Các bài lab Expo/React Native từ môn Lập Trình Thiết Bị Di Động

## Cấu trúc

- **Lab06** - Ứng dụng điện thoại với SelectPhone (Navigation Stack) và BottomTabApp (Tab Navigation)
- **Lab07** - (Sắp tới)

## Công nghệ

- **Framework**: Expo 57.0.31
- **React**: 19.2.3
- **React Native**: 0.86.3
- **TypeScript**: ~6.0.3
- **Navigation**: React Navigation

## Cài đặt & Chạy

```bash
cd Lab06
npm install
npm start
```

## Các lệnh hữu ích

```bash
# Chạy trên iOS
npm run ios

# Chạy trên Android
npm run android

# Chạy trên Web
npm run web

# Type check
npx tsc --noEmit

# Lint
npx expo lint
```
